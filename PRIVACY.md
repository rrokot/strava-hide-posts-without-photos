# Privacy Policy

Strava Feed Filters does not collect, transmit, sell, or share user data.

The extension runs only on the Strava dashboard at `https://www.strava.com/dashboard*`.
It reads the dashboard page in the user's browser so it can add filter controls and hide
matching feed entries locally.

The extension does not send data to the developer, third parties, analytics services, or
external servers. It does not use remote code.

Filter preferences may be stored locally in the user's browser. These local settings remain
on the user's device and are not transmitted by the extension.
